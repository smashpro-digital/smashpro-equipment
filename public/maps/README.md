# Reference cartography

`ne_110m_land.geojson` is Natural Earth's 1:110m land geography, downloaded from
https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_land.geojson
for this shipment-map integration on September 11, 2026.

Natural Earth vector/raster map data is public domain:
https://www.naturalearthdata.com/about/terms-of-use/

This is static reference geography, not satellite imagery, a vessel observation,
or shipment evidence. The displayed shipment coordinates and routes come only
from the Digital HQ public projection. No tile service, imagery key or network
geocoder is used. Attribution remains visible in the map.
