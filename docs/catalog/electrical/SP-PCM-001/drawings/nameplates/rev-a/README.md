# SP-PCM-001 Rev A Nameplate Design Package

## Classification

- Product: `SP-PCM-001` - Power Control Module
- Product revision: `Rev A`
- Artifact: Custom battery box plate for the 2018 F-150 Project Rebirth build
- Artifact status: Design Review
- Application scope: Prototype `SP-PCM-001-A-P001` / Project Rebirth
- Production data plate: Not released

This artwork is the custom application/branding plate designed specifically for the 2018 F-150 Project Rebirth battery box build. It is not the canonical SP-PCM-001 product data plate. It does not replace the product ID, revision, serial, voltage, builder, safety, or regulatory markings required by the catalog standard.

## Future catalog role

Custom plates are planned as an optional personalization layer for compatible SmashPro battery box builds. The F-150 XLT plate belongs to the 2018 F-150 build; it can inform the future option architecture but is not a universal production template or an available-for-sale option.

Future customizable templates may expose approved application text, branding text, and accent treatments. They must remain separate from the controlled product data plate and may not obscure, replace, or contradict required identity, electrical, safety, or regulatory markings. Each customer configuration must retain its own proof, approval status, build association, and revision record.

## Release gate for the canonical product data plate

Before a production data plate can be marked Released, verify and include:

- `SP-PCM-001`
- Product revision
- Assigned serial number
- Accurate system voltage and applicable ratings
- Builder identity
- Required warnings and regulatory markings
- Stable QR destination, if used
- Physical dimensions, hole centers, material, thickness, and manufacturing process
- Font licensing or converted vector outlines
- Drawing approval and effective serial range

Unknown dimensions and manufacturing details remain `TBD`; the current artwork must not be treated as a fabrication drawing.
