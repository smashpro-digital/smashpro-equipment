# Field support gateway

The detailed six-product SURE-CAN grid becomes two compact HQ-backed partner cards: SURE-CAN and No-Spill. Fleet/specification/Passport/attachment/project components and the static catalog remain unchanged. The existing section anchor is retained, while its primary destination is `/media/#field-tested`.

`FieldSupport` mounts the renderer and namespaced stylesheet owned by smashpro-web. The Media library and partner gateway therefore share one card/discount implementation. HQ supplies current public records; no static offer fallback is used. On a shared-asset failure the shell retains the Media link. Deploy the HQ endpoint and Web assets before this build.

The previous `surecan-public.json` remains historical release-source evidence but is no longer imported into the public application. No new product registry, inventory or checkout was introduced. The existing approved manufacturer photos are linked by HQ review records.

Validation: locked dependency TypeScript checks, all 166 tests, production build, public index, MZIGO media, Passport privacy and ARDHI artifact guards. Web's `tools/field-tested/browser-review.cjs` verifies the shared cards, responsive layout, link/disclosure behavior and preservation of the Media shell. The established main-only manual workflow remains the production deployment mechanism; shipment and AKASO activation flags are false for this release.
