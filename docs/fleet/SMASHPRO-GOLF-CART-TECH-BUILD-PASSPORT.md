> **Positioning:** Old cart. New technology.  
> **Asset role:** Dream project · Shop vehicle · Promo vehicle · YouTube build platform  
> **Status:** Sponsor-first donor search  
> **Public page:** `/equipment/golf-cart-tech-build.html`

## 1. Project identity

This project intentionally begins before a donor has been purchased. SmashPro Garage is searching for an inexpensive older electric golf cart and will transform it into a modern connected EV that demonstrates lithium power, programmable performance, digital controls, smart lighting, audio, cameras/security, connectivity, clean electrical distribution, custom styling and practical shop utility.

The vehicle is not positioned as a rental fleet asset. It is a **SmashPro Garage shop and promotional vehicle** whose public record is centered on partnerships, build milestones, YouTube episodes and long-term use.

## 2. Donor acquisition brief

- Target entry point: roughly **$500** when practical.
- Electric E-Z-GO, Club Car and Yamaha platforms are all candidates.
- Dead or missing lead-acid batteries are attractive because the legacy battery bank is expected to be replaced by a modern single lithium system.
- Do not overpay for batteries that are scheduled for removal.
- Prioritize complete chassis, steering, suspension, drivetrain potential and body structure over cosmetics.
- Inspect voltage, motor/controller architecture, wiring, charger, brakes, suspension, frame corrosion and missing components.
- Transport cost is part of true acquisition value.
- Strong aftermarket support and a clear lithium/AC-performance path improve sponsor fit.
- Utility-bodied donors or platforms that can support a convertible rear cargo system are especially attractive.

## 8. Donor-parts recovery ledger

The project should track the resale or reuse of removed donor components so the content can show true net acquisition/build economics.

Potential recovery items include:
- Serviceable lead-acid batteries
- Legacy charger
- Wheels/tires replaced by a partner package
- Original motor/controller after a complete AC conversion
- Extra body panels
- Rear-seat hardware replaced by utility components
- Other reusable accessories

Public build math may present:

**Donor purchase price − recovered donor parts + installed upgrades = net project investment**

## 9. Current donor-selection standard

The ideal donor delivers all five:

**LOW PURCHASE PRICE + STRONG PLATFORM + PARTS AVAILABILITY + GOOD TRANSFORMATION STORY + SPONSOR COMPATIBILITY**

The donor should not be rushed merely to start filming. The empty parking spot is part of the sponsor-first story.
